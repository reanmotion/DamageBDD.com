Welcome to DamageBDD, the powerful and user-friendly behavior testing platform designed to help you automate your application testing process.

In this quick start guide, we'll walk you through setting up an account, writing a simple test and running it.

* Create an Account
:PROPERTIES:
:ID: account
:END:

To get started with DamageBDD, you need to create an account.

You can do this by signing up using the web UI at [[https://run.damagebdd.com][run.damagebdd.com]] or using the curl command:

#+BEGIN_EXPORT html
<div class="code-block">
<pre><code class="language-bash">curl \
  'https://run.damagebdd.com/accounts/create' \
  -H 'Content-Type: application/x-yaml' \
  -d 'email: john.doe@example.com'</code></pre>
</div>
#+END_EXPORT

* Get a Bearer Token
:PROPERTIES:
:ID: token
:END:

After you’ve created an account, you’ll receive an email with a verification link. Click it to activate your account.

Then get a token using this command:

#+BEGIN_EXPORT html
<div class="code-block">
<pre><code class="language-bash">curl \
  'https://run.damagebdd.com/accounts/token' \
  -H 'Content-Type: application/x-yaml' \
  -d 'email: john.doe@example.com'</code></pre>
</div>
#+END_EXPORT

This will return a bearer token that looks like:

#+BEGIN_EXPORT html
<div class="code-block">
<pre><code class="language-json">{"token":"your_bearer_token_here"}</code></pre>
</div>
#+END_EXPORT

* Quick Introduction to Gherkin
:PROPERTIES:
:ID: gherkin
:END:

Gherkin is a simple language that lets you describe software behavior without detailing how that functionality is implemented.

Example:

#+BEGIN_EXPORT html
<div class="code-block">
<pre><code class="language-gherkin">Feature: Login
  Scenario: User logs in with valid credentials
    Given a user with email "user@example.com" and password "pass"
    When they log in
    Then they should see the dashboard</code></pre>
</div>
#+END_EXPORT

* Running a Test
:PROPERTIES:
:ID: test
:END:

To run a test, you must first write a feature file and then post it using the API:

#+BEGIN_EXPORT html
<div class="code-block">
<pre><code class="language-bash">curl \
  'https://run.damagebdd.com/tests/run' \
  -H 'Authorization: Bearer your_bearer_token_here' \
  -H 'Content-Type: application/x-yaml' \
  -d '
  feature: |
    Feature: Hello World
      Scenario: Print a message
        Given I print "Hello, World!"'
</code></pre>
</div>
